QRoo for Android

QRoo for Android is a native Kotlin and Jetpack Compose app. It can scan, create, customize, organize, import, export, and share QR codes. A selected QR code can also be placed in a home screen widget or saved to Google Wallet.

Status: closed testing before the Google Play release.

Google Wallet integration ↓ ↓ ↓

QRoo lets a user save a QR code they created or scanned as a Generic Pass in their own Google Wallet.

  1. The user opens a saved QR code and taps the official Add to Google Wallet button.
  2. QRoo explains which QR code and visual details will be sent, and asks for confirmation.
  3. The QRoo pass service securely prepares the Generic Pass over HTTPS.
  4. Google Wallet shows its native preview; the pass is saved only when the user confirms in Google Wallet.

QRoo does not issue payment cards, identity documents, tickets, loyalty cards, or third-party credentials. It does not send QR content to the pass service unless the user explicitly starts and confirms this optional Wallet flow.
